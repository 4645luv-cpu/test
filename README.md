# 🎷 サックス移調くん

楽譜の写真をアップロードすると、AI(Claude)が楽譜を読み取り、アルトサックス(E♭管)用に移調した五線譜とカタカナのドレミを表示するWebアプリです。

## 機能

- 📷 スマホのカメラ撮影・写真選択・ドラッグ&ドロップに対応
- 🤖 Claude(vision)による楽譜の自動認識(音符・調号・拍子・楽器名)
- 🎼 元の譜が何管(C / B♭ / E♭ / F)かを自動判定(手動で上書きも可能)
- 🎷 アルトサックス用に移調した五線譜を新規描画(VexFlow使用)
- 🈁 各音符の下にカタカナのドレミを表示(ドレミのみの表示も可能)
- 🔄 テナー/ソプラノサックス(B♭管)への切り替えにも対応
- 👀 「元の譜(認識結果)」タブでAIの読み取り結果を確認可能

## セットアップ(Vercel)

1. このリポジトリをVercelにデプロイ(静的ファイル + `api/` のサーバーレス関数が自動で認識されます)
2. **Vercelのプロジェクト設定 → Environment Variables に `ANTHROPIC_API_KEY` を設定**(必須)
   - APIキーは https://platform.claude.com/ で取得できます(従量課金)
3. 再デプロイすると `/api/analyze` が有効になります

## 構成

| パス | 内容 |
|---|---|
| `index.html` / `app.js` / `style.css` | フロントエンド(移調アプリ本体) |
| `music.js` | 移調・音名・調号の音楽理論ロジック(Nodeでもテスト可能) |
| `api/analyze.js` | Vercelサーバーレス関数。Claude APIで楽譜写真を解析 |
| `lib/vexflow.js` | 五線譜描画ライブラリ VexFlow 4.2.3(同梱) |
| `alarm/` | 以前のアラームアプリ(`/alarm/` で引き続き利用可能) |

## 注意

- AIによる読み取りのため、複雑な楽譜(和音・多声部・かすれた印刷など)では音を間違えることがあります。「元の譜(認識結果)」タブで確認してください。
- 1回の解析でClaude APIの利用料金が発生します(画像1枚あたり数円〜十数円程度)。
